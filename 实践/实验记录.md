## R4 串行与并发的固定等待实验：已执行

原始结果：results/comparison.json；程序：compare.py。5 对运行；相同两个资料分片、相同脚本策略、相同只读工具，每次策略调用注入 .02 秒等待。每组均 4 次策略调用、2 次工具查询、确定代码汇总（0 模型汇总调用）。

- 顺序隔离循环均值：0.093850 秒。
- 双工作者并发均值：0.049677 秒。
- 墙钟比值（顺序/并发）：1.889，由上述原始结果计算，不能外推到服务。
- 每组两个结果的 JSON 传输字节：268；字节不是 token。提示输入重复和真实服务排队没有模拟。

这只表明可重叠等待在此环境缩短墙钟，不证明多 Agent 提高准确率或推理能力。两条顺序循环同样隔离上下文，不是共享上下文单 Agent 基线。
